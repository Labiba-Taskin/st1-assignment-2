Before using AI, I built a simple appointment system with a list of dictionaries and two functions book_appointment and display_appointments. It stored patient, practitioner and time.

AI helped me understand that my code lacked validation and that I should check for empty strings and duplicate bookings. It explained my functions clearly.

AI made assumptions that I wanted a full menu system and file storage, which were not required for this stage.

I verified the AI output by running both versions with normal inputs, blank name, and None values. The human version raised ValueError as expected.

The engineering work that remained for me was deciding what is actually needed, testing edge cases, and keeping the code simple and explainable.
